# Paradise Nursery Shopping Application

A responsive plant-shop application built with React, Vite, Redux Toolkit, and CSS. Browse houseplants, add them to a cart, change quantities, remove items, and view the live total.

## Features
- Landing page with the company name and **Get Started** button
- About Us company information
- Plant catalog grouped by category
- Product images, descriptions, prices, and add-to-cart controls
- Redux Toolkit cart state with `addItem`, `removeItem`, and `updateQuantity`
- Cart badge, quantity controls, item subtotals, and grand total
- Continue Shopping and Checkout (demo message)
- Responsive desktop and mobile styling

## Technology
React 18, JavaScript, Redux Toolkit, React Redux, Vite, CSS3.

## Run locally
1. Install Node.js (LTS).
2. Extract/clone this project and open its folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to verify a production build.
